📞 VoIP (Voice over IP) Communication System with ARP
Voice Transmission Over IP Networks:

Implements real-time voice communication using IP protocols, enabling voice calls over the internet.

SIP Protocol for Call Management:

Utilizes Session Initiation Protocol (SIP) for establishing, maintaining, and terminating voice calls.

ARP for IP-to-MAC Address Mapping:

Uses ARP (Address Resolution Protocol) to map IP addresses to MAC addresses, ensuring correct routing of voice packets within the local network.

Audio Compression and Transmission:

Implements audio codecs (e.g., G.711, G.729) to compress voice data for efficient transmission over the network.

Peer-to-Peer (P2P) Architecture:

Establishes direct communication between devices, reducing server load and improving call quality.

Real-Time Audio Streaming & Security:

Uses RTP (Real-Time Protocol) for streaming audio with low latency, and employs SRTP (Secure Real-time Transport Protocol) and TLS encryption for secure communications.
